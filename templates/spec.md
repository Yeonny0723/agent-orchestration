# 기능 이름

## 기능 목표

사용자가 달성하려는 결과와 성공 기준을 적는다.

## 현재 구조와 제약

관련 코드, 문서, 공개 계약, 데이터 흐름과 운영·호환성 제약을 적는다.

## 사용자 Use Case

선언한 입력 경계에서 발견한 정상 및 예외 Use Case와 MVP 포함 여부를 적는다.

## 예외와 운영 위험

부분 실패, 오류 전달, 복구, 비용, 크기, 성능, 로그, 보안과 책임 소유권 중 관련 항목을 적는다.

## 결정 기록

결정과 이유, 영향을 적는다. 필요한 경우 `검토 중`, `잠정 결정`, `확정`, `후순위` 상태를 표시한다.

## MVP 제외

현재 구현에서 의도적으로 제외하는 범위를 적는다.

## 완료 기준

사용자에게 보이는 행위와 검증 가능한 완료 조건을 적는다.

## Task 계획

- [ ] 리뷰 가능한 한 단위의 작업을 적는다.
