# 활동 요약 PDF · Spec 완성 샘플

[Spec 본문](./spec.md)은 가상의 독서 모임 도구에 월간 활동 요약 PDF 내보내기를 추가하는 작성 예시다. 특정 조직·제품·저장소의 요구사항이나 구현을 재현하지 않는다. 모든 명칭·입력·API·데이터 구조·수치·운영 정책은 이 예시를 위해 구성했다.

[Spec 템플릿](../../../templates/spec.md)은 작성 기준이고 이 샘플은 그 적용 방법을 보여 준다. 정책의 `확정`은 가상 설계 안에서 채택했다는 뜻이다. 실제 코드 조사·사용자 승인·기능 검증 결과를 뜻하지 않으며 Task는 모두 미착수, 테스트는 미실행이다.

## 읽는 순서

| Spec 절 | 확인할 작성 방식 |
| --- | --- |
| 1~2 | 사용자 결과·출시 범위를 먼저 쓰고 재진입·입력 변경·진행 중 행동·실패·재시도·만료를 설명 |
| 3~4 | 가정과 미확인 사항을 밝히고 결정 성숙도·외부 의존성을 구분 |
| 5~6 | 그림에는 관계·흐름, 글에는 상태 소유권·예외·운영 판단을 배치 |
| 7~8 | API 요청·응답·오류와 필드별 저장 이유, 기존 모임 엔티티 재사용을 설명 |
| 9~10 | 제외 범위, 선행 조건·예상 시간·착수·완료 상태와 목업·실제 연계를 구분 |
| 11 | 문서 기준본 검토와 구현·연계 검증 완료를 구분 |
