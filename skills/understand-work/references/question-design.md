# 작업 이해 질문 설계

출처: 로컬 Adept `C:/Users/kkjuyeon/orca/khala/adept/references/question-design.md`의 상황 우선 질문 원칙을 작업 변경 이해 목적에 맞게 채택했다.

## 유지할 원칙

- 문서 제목이나 문구 회상보다 실제 유지보수 상황을 제시한다.
- 실제 업무와 같은 응답 형태를 요구한다. 설명, 진단 순서, 변경 위치 또는 검증 선택을 묻는다.
- 문항 하나에는 판단 하나만 둔다.
- 근거에 없는 내용을 정답처럼 요구하지 않는다.
- 대부분 성공할 수 있지만 추측만으로 맞힐 수 없는 난이도를 사용한다.
- 사람 간 점수나 순위를 만들지 않는다.

## 이 플러그인의 조정

핵심 주장은 질문 전에 전수 목록화한다. 그러나 주장마다 질문 하나를 만들지 않는다. 유지보수 위험을 기준으로 최대 5문항만 선정하고, 적용할 근거가 없는 이해 축은 생략한다.

각 답변 피드백에는 판단, 빠진 reasoning, 보완 설명과 실제 근거 위치를 포함한다. 기대 답을 별도 정답지 파일로 저장하지 않는다.
