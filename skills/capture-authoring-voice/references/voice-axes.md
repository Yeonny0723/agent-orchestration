# 문체 인터뷰 축

각 질문은 한 번에 하나씩 제시한다. 선택지는 예시이며 자유 응답으로 대체할 수 있다.

1. 문장 길이와 호흡: 짧고 단정함 / 중간 길이 / 긴 설명형
2. 어미와 경어체: 합니다체 / 해요체 / 간결한 서술체
3. PR 최상단 내용과 섹션 순서: 결론 우선 / 문제 우선 / 검증 우선
4. 비유 허용 범위: 금지 / 드물게 / 설명에 유효할 때 허용
5. 기술용어 원어 유지 정도: 원어 우선 / 한국어 병기 / 한국어 우선
6. 불확실성 표현법: 확률 명시 / 조건 명시 / 짧은 경고
7. 금지 표현: 사용자가 싫어하는 상투어와 과장 표현을 원문으로 수집
8. 강조 수단: 굵게 / 목록 / 최소 강조
9. 코드와 명령 인용 밀도: 필요한 것만 / 검증 중심 / 상세 인용
10. 독자 가정: 본인 / 같은 팀 개발자 / 비개발 이해관계자

각 축에는 선택한 값과 선택적으로 사용자 원문 예시를 기록한다.
