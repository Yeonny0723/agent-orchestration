# 의사결정 우선 그릴

## 준비

brainstorming에서 spec의 범위, 외부 행위, 공개 계약, 보안, 운영, 완료 기준과 PR 경계에 영향을 주는 결정을 전수 목록화한다. 대화에서 이미 미결정으로 드러난 항목뿐 아니라 agent가 관례로 대신 정하려는 항목도 포함한다.

질문과 결정 기록은 외부 `grill-with-docs`를 인터뷰 엔진으로 사용한다. 해당 skill이 없으면 축소 절차로 대신하지 말고 `setup-orchestration`으로 돌려보낸다. 용어 정리나 ADR 후보가 생기면 외부 `domain-modeling`을 사용하되, 단순 작업 메모를 ADR로 만들지 않는다.

## 질문 루프

1. 영향도가 높은 결정부터 한 번에 한 질문만 제시한다.
2. 상호 배타적인 선택지 2~3개와 각 트레이드오프를 설명한다.
3. 추천안과 추천 이유를 먼저 밝힌다.
4. 사용자의 선택과 이유를 결정 목록에 기록한다.
5. spec 작성 중 새 실질적 결정이 발견되면 작성을 멈추고 이 루프로 돌아온다.

목록의 모든 결정이 확정되기 전에는 spec 작성 금지다. 소형 단축형은 모호함을 해소하는 최대 두 질문만 사용한다.

## 기록 위치

결정 배경과 이유는 spec에 둔다. `CONTEXT.md`에는 용어만 두고, 여러 작업에 영향을 주며 대안과 장기 결과가 있는 결정만 ADR 후보로 처리한다.

## 문체

질문 전에 `$AGENT_ORCHESTRATION_HOME/voice-profile.md` 또는 `~/.agent-orchestration/voice-profile.md`를 읽는다. 프로파일은 질문 문체에만 적용하고 선택지 구조나 판단 계약을 바꾸지 않는다. 파일이 없어도 차단하지 않는다.
