# 공통 mutation 선택

mutation은 문법 오류가 아니라 검증하려는 행위를 작게 깨뜨려야 한다. 컴파일 자체가 계약이 아닌 한 import 또는 compile 실패만 일으키는 변경은 선택하지 않는다.

- boolean 반전: 권한이나 활성 조건을 반대로 만든다.
- 경계값 이동: `<`를 `<=`로 바꾸거나 임계값을 한 단계 이동한다.
- 예외 제거: 거부해야 할 입력을 통과시킨다.
- 필터 완화: 제외해야 할 항목 하나가 포함되게 한다.
- 상태 전이 생략: 필수 상태 할당 한 줄을 제거한다.

한 번에 하나만 적용하고, 어떤 테스트가 왜 실패해야 하는지 mutation 전에 명시한다.
