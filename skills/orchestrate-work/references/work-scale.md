# 작업 규모 판정

출처: 로컬 `C:/Users/kkjuyeon/.claude/skills/work-scale-workflow`의 규모 판정 기준을 이 플러그인의 배포 가능한 reference로 채택했다.

규모는 예상 시간이 아니라 독립적으로 병합하고 검증할 수 있는 산출물 경계로 판정한다.

| 규모 | 기준 | 기본 절차 |
| --- | --- | --- |
| 소형 | 명확한 버그나 한두 파일 변경이며 PR 하나로 끝난다 | 모호함이 없으면 짧게 진행한다 |
| 중형 | 하나의 기능이 여러 파일이나 모듈에 걸치지만 PR 하나로 완결된다 | 모든 spec 결정을 먼저 확정한다 |
| 대형 | 독립 배포 가능한 모듈이나 PR이 둘 이상이다 | 전체 spec 뒤 산출물별 plan과 PR로 분리한다 |

파일 수만으로 판정하지 않는다. 공개 계약, 데이터 소유권, 운영 경계 또는 독립 검증 단위가 나뉘면 더 큰 규모로 올린다.
