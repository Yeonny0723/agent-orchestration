# React 컨벤션

- 컴포넌트는 하나의 사용자 책임에 집중하고 데이터 로딩, 상태 전이와 표현을 필요에 따라 분리한다.
- 파생 가능한 상태를 별도 state로 중복 저장하지 않는다.
- effect는 외부 시스템 동기화에만 사용하고 이벤트에서 처리할 일을 effect로 우회하지 않는다.
- boolean prop이 늘어나면 compound component, 명시적 variant 또는 구성 가능한 child API를 검토한다.
- 목록 key에는 안정된 도메인 식별자를 사용한다.
- 접근 가능한 기본 HTML 요소와 명시적 label을 우선한다.
- 사용자에게 노출할 오류와 내부 진단용 오류를 구분한다. 사용자가 조치할 수 있는 메시지만 UI에 표시하고 내부 정보는 노출하지 않는다.
- 불필요한 memoization을 추가하지 말고 측정된 렌더링 또는 참조 안정성 문제에 적용한다.
- 서버와 클라이언트 경계를 사용하는 프레임워크에서는 클라이언트 번들 범위를 최소화한다.
